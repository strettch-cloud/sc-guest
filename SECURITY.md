# Security

Please report security problems privately to security@cloud.strettch.com,
not in a public issue.

Include:

- what an attacker can do, and how
- the version from `dpkg-query -W sc-guest`, and the system
- steps to reproduce it, if you have them

Leave out real passwords and user data.

## Supported versions

Fixes go into the latest release. Strettch Cloud VMs get it from the Strettch
Cloud APT repository with `apt upgrade`.
